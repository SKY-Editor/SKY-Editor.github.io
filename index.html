Features

远空之内，每一处细节都为创作而备

Distant SKY · Everything You Need to Build

01

编译级速度 Compiler Speed

沿用 TurboWarp 编译器，把积木脚本编译为 JavaScript 执行，复杂项目的帧率与响应显著优于原生解释器。

02

网页与桌面双形态 Web & Desktop

浏览器打开即用，也可作为桌面应用安装运行，两种形态共用同一套项目格式与扩展。

03

多主题隔离 Theme Isolation

SKY Editor 定制样式限定在专属作用域内生效，与其它主题共存互不干扰，切换主题不掉样式、不污染上游。

04

窗口化界面 Windowed UI

面板即窗口，支持停靠、浮动与贴边，大屏创作时可以把工作区铺开成你想要的样子。

05

扩展生态聚合 Ecosystem

聚合 AstraEditor、02Engine、Bilup、FrostEditor、RemixWarp、NeoWarp 等来源的扩展与扩展库，一处配齐。

06

项目兼容 Compatibility

直接打开标准 .sb3 与各家改版产出的项目文件，扩展齐全即可运行，不做格式转换。

07

打包与加密 Packager

把作品打包成 HTML / zip / 桌面应用，并支持作品加密，交付与分发都在编辑器内完成。

08

媒体与音频 Media & Audio

独立的音频引擎与音乐播放器，素材导入、音效处理与后台播放都有配套能力。

One Editor, One Sky

同步策略

SKYEditor 只与 TurboWarp 一条主线同步，保证内核干净、可随时跟上上游；其它改版的优秀功能以「移植」方式引入，不与任何一家做 git 同步。

聚合来源

AstraEditor 02Engine Bilup FrostEditor RemixWarp NeoWarp PenguinMod Mist SharkPool

兼容性边界

项目类型支持情况
标准 .sb3（普通积木 + 官方扩展）可打开运行
各家改版的自定义扩展项目扩展齐全即可运行
02Engine 的内联 JS / 自定义报告器暂不支持
NeoWarp 的 .npnp 私有加密格式不适用

我们如实标注边界，不承诺做不到的兼容。
